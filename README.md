# OnlyBudget

A minimal, honest budgeting app. No bank sync, no accounts, no ads, no bait-and-switch subscriptions. You speak or type your income, expenses and goals in plain language, and the app does the categorizing for you.

```
"spent 12 dollars on lunch"        → $12 · Money out · Dining out · today
"got paid 2400"                     → $2,400 · Money in · Salary
"goal: save 500 for a trip by dec"  → Goal: Trip, $500 by December 31
"add 100 to the trip goal"          → +$100 toward Trip (logged as a transfer)
```

## Principles (non-negotiable)

1. **No bank linking, ever.** Not as a feature, not as an upsell.
2. **Voice and text are equal.** Both go through the same parser and the same confirmation card.
3. **No dark patterns.** No trials that flip into subscriptions. Nothing the user entered is ever paywalled.
4. **Local-first.** SQLite on the device. Works with zero network. Export and encrypted backup from day one.
5. **Calm, not gamified.** Plain sentences, no streaks, no red badges.

## Languages

The app speaks eight languages: English, Spanish, French, Italian, German, Chinese (Simplified), Japanese, and Korean. It follows the phone's language by default and can be switched in Settings. Each language has:

- a full UI string table and plain-language sentence set (`src/i18n/locales/<code>.ts`),
- a parser language pack with its own number words, verbs, category keywords, date phrases, and goal patterns (`src/parser/packs/<code>.ts`),
- locale-correct money and date formatting (`1.234,50 €`, `¥1,200`, `9月3日`),
- the matching speech-recognizer locale.

Chinese, Japanese, and Korean use substring matching instead of word tokens, convert native numerals (十二, 1万2千, 2만5천), and learn whole phrases from corrections. Adding a language is two files plus a line in each registry.

## Stack

- React Native + Expo SDK 57, TypeScript, expo-router
- `expo-sqlite` for storage, `zustand` for state, `expo-localization` for the phone's language
- `expo-speech-recognition` (platform-native, on-device where supported) for voice
- `expo-file-system` + `expo-sharing` for export; `@noble/ciphers` + `@noble/hashes` for passphrase-encrypted backups
- No backend. Optional Tier 2 parsing assist calls the Anthropic API directly with the user's own key, off by default.

## Running it

Voice and SQLite are native modules, so use a development build rather than Expo Go.

```bash
npm install
npx expo run:ios        # or: npx expo run:android
```

The native `ios/` and `android/` folders are generated by `expo prebuild` and are git-ignored.

Web build and containers (optional; the phone builds are the product):

```bash
npm run web         # dev server in the browser (Chrome/Edge for voice)
npm run build:web   # static web build in dist/ with PWA manifest and service worker
podman build -t onlybudget-web . && podman run --rm -p 8080:8080 onlybudget-web
```

See [docs/CONTAINERS.md](docs/CONTAINERS.md) for Podman, Kubernetes and OpenShift deployment, and for building the Android APK inside a container.

Checks:

```bash
npm test          # jest: parser (8 languages), plain-language, i18n formatting, recurring, export, crypto
npm run typecheck # tsc --noEmit
npm run icons     # regenerate assets/*.png from scripts/generate-icons.js
```

## How parsing works

**Tier 1 (always, offline, instant)** in `src/parser/`, driven by the active language pack:

- Number words → digits (`twelve dollars`, `doscientos cincuenta`, `zweihundertfünfzig`, `一千二百`, `2만5천`, `2.4k`).
- Date phrases are pulled out first so `sept 3` is never mistaken for an amount (`yesterday`, `last friday`, `on the 1st`, `3 days ago`, `9/3`).
- Amount: prefers a number with a currency marker, else the first bare number; ordinals, times and percentages are skipped.
- Type: income verbs (`got paid`, `earned`, `refund`…) vs expense verbs (`spent`, `paid`, `bought`…). If neither, the category decides; if nothing, expense with a hint.
- Category: learned words (from user corrections) → custom category names → the pack's keyword dictionary, longest phrase first (`gas bill` beats `gas`; `电影` beats `电`).
- Goals: `goal: …`, `save X for Y by Z`, `I want to save…`. Contributions to an existing goal: `add 100 to the trip goal`, `put 50 toward japan`.

Every parse produces a confidence and plain hints ("Not sure about the category. Tap it to change."). Nothing is saved without the confirmation card.

**Tier 2 (optional)**: if the user turns on *Smart parsing assist* in Settings and adds their own Anthropic API key, a low-confidence phrase is sent to the API with a strict JSON schema. It runs with an 8-second timeout and any failure (offline, bad key) falls back to "review manually". Off by default; nothing leaves the device unless the user opts in.

**Learning**: when the user changes the category on the confirmation card, the meaningful words of the phrase are stored in `keyword_mappings` and take priority next time. They can be reviewed and removed under Settings → Learned words.

## Data

SQLite schema in `src/db/database.ts` (versioned with `PRAGMA user_version`; v2 adds `settings.language`). Tables: `transactions`, `categories` (with a `kind` column and optional `monthly_limit`), `recurring_rules`, `goals`, `settings` (single row), `keyword_mappings`.

Recurring rules are caught up on every launch and whenever a rule is saved: every due occurrence up to today is inserted as a transaction flagged `is_recurring_instance`, and `next_occurrence` moves forward. Monthly rules keep their day-of-month anchor (the 31st becomes the 28th in February and returns to the 31st in March).

Backups: CSV (entries), a readable text summary, a full JSON backup, and a passphrase-encrypted backup (scrypt + XChaCha20-Poly1305). Restore accepts either JSON form and replaces everything on the device after confirmation.

## Monetization

One-time purchase or a free app with one optional one-time "supporter" unlock for cosmetics only. Never gated: recurring entries, goals, exports, or any tracking. No subscriptions, no trials, no ads.

## Status

Everything in the v1 must-have list is implemented, in eight languages: voice + text entry, Tier 1 parser with learning, confirmation card, default + custom categories with optional limits, recurring entries, monthly overview, goals with plain-language pace, CSV/summary/JSON/encrypted export and restore, full offline operation, onboarding without sign-up, light/dark theme, optional daily reminder. Tier 2 assist is implemented behind an opt-in.

Not built (v1.5 candidates): household sharing between two devices, home-screen widget, multi-currency entries, trend charts. The non-English copy was written in one pass and should get a native-speaker review before release.

Verified in this environment: unit tests, TypeScript, and a Metro/Hermes bundle. Not verified here: running on a physical device or simulator (no macOS/Android toolchain in the build container). Do that first with `npx expo run:ios` / `run:android`, and test voice on a real device since simulators have no on-device recognizer.
